# Copy MVP 实现计划

> **给自动化开发代理的说明：** 必须使用 `superpowers:subagent-driven-development`（推荐）或 `superpowers:executing-plans`，按任务逐步实现本计划。任务步骤使用复选框（`- [ ]`）便于跟踪。

**目标：** 构建第一版本地 Mac 剪贴板历史 MVP，包括菜单栏应用外壳、本地文字/链接/图片记录、搜索、去重和剪贴板恢复。

**架构：** 使用 Swift Package 组织项目，包含可复用的 `CopyCore` 核心库、可执行的 `CopyApp` 应用目标，以及 `CopyCoreTests` 测试目标。平台无关的历史记录逻辑放在核心库中，AppKit/SwiftUI 的剪贴板和界面逻辑放在应用目标中。

**技术栈：** Swift 6.3、SwiftUI、AppKit、XCTest、本地 JSON 元数据存储、本地文件系统图片存储。

---

## 文件结构

- `Package.swift`：Swift Package 定义，包含 `CopyCore`、`CopyApp` 和测试目标。
- `Sources/CopyCore/ClipboardItem.swift`：剪贴板记录模型和记录类型。
- `Sources/CopyCore/ClipboardNormalizer.swift`：文字修剪、URL 识别、预览生成和稳定内容 hash。
- `Sources/CopyCore/ClipboardHistoryStore.swift`：内存历史记录行为，包括去重、搜索、删除、清空和保留数量限制。
- `Sources/CopyCore/LocalHistoryRepository.swift`：基于 JSON 的历史元数据持久化。
- `Sources/CopyCore/ImageFileStore.swift`：本地图片原图/缩略图路径和文件清理。
- `Sources/CopyApp/CopyApp.swift`：SwiftUI 应用入口和菜单栏集成。
- `Sources/CopyApp/AppModel.swift`：应用状态、剪贴板轮询、暂停记录和存储协调。
- `Sources/CopyApp/PasteboardClient.swift`：AppKit 剪贴板读写适配器。
- `Sources/CopyApp/HistoryPanelView.swift`：可搜索的历史记录界面。
- `Tests/CopyCoreTests/ClipboardNormalizerTests.swift`：核心归一化测试。
- `Tests/CopyCoreTests/ClipboardHistoryStoreTests.swift`：去重、搜索、删除和保留数量测试。
- `Tests/CopyCoreTests/LocalHistoryRepositoryTests.swift`：JSON 持久化测试。
- `Tests/CopyCoreTests/ImageFileStoreTests.swift`：图片路径和清理测试。

public enum ClipboardItemType: String, Codable, Equatable, Sendable {

}

## 任务 2：历史记录存储行为

**文件：**
- 新建：`Sources/CopyCore/ClipboardHistoryStore.swift`
- 新建：`Tests/CopyCoreTests/ClipboardHistoryStoreTests.swift`

- [ ] **步骤 1：编写失败的历史存储测试**

创建测试覆盖：

- 插入文字记录后，新记录位于列表顶部。
- 插入和最新记录重复的内容时，更新已有记录，不新增第二行。
- 插入和较早历史重复的内容时，把旧记录移到顶部并增加 `useCount`。
- 搜索能匹配预览、普通文字和 URL。
- 保留数量限制会裁掉最旧记录。
- 删除和清空会移除记录。

- [ ] **步骤 2：运行测试并确认红灯**

运行：`swift test --filter ClipboardHistoryStoreTests`

预期：构建失败，因为 `ClipboardHistoryStore` 尚不存在。

- [ ] **步骤 3：实现历史记录存储**

创建 `ClipboardHistoryStore`，作为小型值类型存储，提供这些公开方法：

```swift
public init(items: [ClipboardItem] = [], retentionLimit: Int? = 1000)
public var items: [ClipboardItem] { get }
public mutating func record(_ item: ClipboardItem, now: Date) -> ClipboardItem
public func search(_ query: String) -> [ClipboardItem]
public mutating func delete(id: UUID)
public mutating func clear()
```

`record` 方法必须使用 `contentHash` 去重，并保持最新记录在最前面。
