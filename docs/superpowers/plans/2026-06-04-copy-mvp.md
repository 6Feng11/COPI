# Copy MVP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the first local Mac clipboard history MVP: menu bar app shell, local text/link/image records, search, deduplication, and pasteboard restore.

**Architecture:** Use a Swift Package with a reusable `CopyCore` library, an executable `CopyApp`, and `CopyCoreTests`. Keep platform-neutral history logic in the core library and keep AppKit/SwiftUI pasteboard and UI behavior in the app target.

**Tech Stack:** Swift 6.3, SwiftUI, AppKit, XCTest, local JSON persistence for the first executable MVP, local file storage for copied images.

---

## File Map

- `Package.swift`: Swift package definition for `CopyCore`, `CopyApp`, and tests.
- `Sources/CopyCore/ClipboardItem.swift`: Clipboard record model and item type.
- `Sources/CopyCore/ClipboardNormalizer.swift`: Text trimming, URL detection, preview generation, and stable content hashing.
- `Sources/CopyCore/ClipboardHistoryStore.swift`: In-memory history behavior, deduplication, search, deletion, clearing, and retention limit.
- `Sources/CopyCore/LocalHistoryRepository.swift`: JSON-backed persistence for history metadata.
- `Sources/CopyCore/ImageFileStore.swift`: Local image/original/thumbnail paths and file cleanup.
- `Sources/CopyApp/CopyApp.swift`: SwiftUI app entry point and menu bar integration.
- `Sources/CopyApp/AppModel.swift`: App-facing state, pasteboard polling, recording pause, and store coordination.
- `Sources/CopyApp/PasteboardClient.swift`: AppKit pasteboard read/write adapter.
- `Sources/CopyApp/HistoryPanelView.swift`: Searchable history UI.
- `Tests/CopyCoreTests/ClipboardNormalizerTests.swift`: Core normalization tests.
- `Tests/CopyCoreTests/ClipboardHistoryStoreTests.swift`: Deduplication, search, deletion, and retention tests.
- `Tests/CopyCoreTests/LocalHistoryRepositoryTests.swift`: JSON persistence tests.
- `Tests/CopyCoreTests/ImageFileStoreTests.swift`: Image path and cleanup tests.
